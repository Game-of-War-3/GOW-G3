# GOW-G3

A simple board game repository with a minimal command-line Tic-Tac-Toe implementation.

## Project structure

- `/home/runner/work/GOW-G3/GOW-G3/game.py` - core game logic and a tiny CLI loop
- `/home/runner/work/GOW-G3/GOW-G3/tests/test_game.py` - focused unit tests

## Run the game

```bash
python game.py
```

## Run tests

```bash
python -m unittest discover -s tests -p "test_*.py"
```
